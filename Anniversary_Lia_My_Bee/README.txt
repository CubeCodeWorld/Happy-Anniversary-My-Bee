ANNIVERSARY WEBSITE — LIA / MY BEE
===================================

Isi folder:
- index.html
- style.css
- script.js
- assets/our-story.jpg
- assets/first-chat.jpg
- assets/kota-ini-tak-sama-tanpamu.mp3

CARA PALING CEPAT PREVIEW
1. Extract ZIP.
2. Double-click index.html.
3. Klik "Open our story" atau "Play our song" supaya musik mulai.
   (Browser modern biasanya tidak mengizinkan musik autoplay sebelum ada interaksi.)

CARA ONLINE PALING CEPAT
- Netlify Drop: drag seluruh folder hasil extract.
- Vercel: buat project baru lalu upload/deploy folder ini.
- GitHub Pages: upload isi folder ke repository lalu aktifkan Pages.

CATATAN
Website dibuat mobile-first dan cocok dibuka lewat HP.
Jangan ubah nama file di folder assets kecuali juga memperbarui referensinya di index.html.
