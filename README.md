# Happy-Anniversary-My-Bee
Sebuah cerita kecil tentang dua orang yang dipertemukan dengan cara tak terduga, lalu perlahan saling mengenal, saling nyaman, dan akhirnya memilih berjalan bersama. Web ini dibuat untuk mengenang satu tahun perjalanan sejak 23 September 2025—tentang obrolan sederhana, momen kecil, tawa, pelukan, dan harapan untuk terus saling memilih.
